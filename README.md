# Norah Alaqeel — Portfolio

Static site, no build step. Open `index.html` via a local server (e.g. VS Code "Live Server") — not by double-clicking, since the Keeta PDF loads over HTTP.

## Deploy (Vercel)
1. Create a public GitHub repo `noura-portfolio` and push this folder.
2. vercel.com → Add New Project → import the repo → Framework: Other → Deploy.
Every push to `main` redeploys automatically.
